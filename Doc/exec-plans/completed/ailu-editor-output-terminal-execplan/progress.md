## Decision Log

- 2026-10-20: see global D1–D6 in `README.md`; nothing superseded.
- 2026-10-20: M1 uses a shared-state `IAppender` adapter owned by `LogMgr`; `EditorLogService::BeginShutdown()` invalidates the state, drains pending records, then releases the service owner before `LogMgr::Shutdown()` deletes the adapter. This avoids a raw service pointer/UAF without adding `RemoveAppender()`.
- 2026-10-20: Pending admission drops the newest incoming record when count/bytes are full; oversized records are truncated with a marker to the pending byte cap and counted. History evicts oldest records to preserve bounded memory and stable increasing sequence IDs.
- 2026-10-20: `EditorApp::Initialize()` failure after `Application::Initialize()` now enters the existing `Finalize()` path so partially initialized runtime state is unwound before log shutdown; service registration remains immediately after `LogMgr::Init()`.
- 2026-10-20: `JsonArchive::HasField()` treats a loading array name as a decimal index only when parsing consumes the full name and the index is in range; object-field behavior is unchanged.
- 2026-10-20: Automation pipe security uses the current logon SID and fails closed if the ACL cannot be built, avoiding the previous default-descriptor access-denied behavior without granting access to all users.
- 2026-10-20: Output severity/module colors are EditorConfig preferences edited through a dedicated native Editor Preferences Dock; Output only applies them to the Level and Module cells and updates live without changing the global UI theme.
- 2026-10-20: Editor Preferences is the single native settings surface for Output colors, UITheme and EditorStyle; the legacy ImGui StyleThemeEditor entry is no longer exposed from EditorLayer.
- 2026-10-20: M3 keeps the registry separate from `CommandManager`; Terminal owns only local transcript/history, while EditorApp owns the registry lifetime. `clear` is represented as a result flag so it cannot clear M1 engine log history.
- 2026-10-20: InputBlock ignores Up/Down/Tab in its generic character insertion branch so reusable consumers can implement navigation/completion without inserting control characters; Terminal uses the dedicated submit event for Enter.
- 2026-10-20: M4 redirected launches use `STARTUPINFOEX` plus `PROC_THREAD_ATTRIBUTE_HANDLE_LIST`; all three standard handles are always valid backend-owned inheritable handles, using NUL for an unredirected stream. `bInheritHandles` is forced true only for redirected launches; legacy launches retain `ProcessStartInfo::InheritHandles`.
- 2026-10-20: Keep Player out of default configure/build presets with `AILU_BUILD_PLAYER=OFF`; opt-in Player builds use separate binary trees and workflow presets that configure with `AILU_BUILD_PLAYER=ON` before building `package_player`. This avoids restoring the previously unwanted default Player build while giving Editor a valid package entry point.
- 2026-10-20: Automation methods remain single-source in `EditorAutomationRegistry`; Terminal registration is a presentation bridge that captures method descriptors and invokes the same handler on the Editor main thread. Complex Terminal values use the existing `AutomationJson` codec rather than a second value parser.
- 2026-10-20: Output source navigation stays at the table-cell boundary: `TableDataSource` declares link capability and activation, `UITableElement` owns hover/click routing, and Output resolves source paths and invokes VSCode. The Asset Browser double-click behavior is a reference for opening assets, not a change to Output's requested Ctrl+click interaction.

## Surprises & Discoveries

- `LogMgr` holds output mutex while invoking appenders; sink callback must be short and never log recursively.
- `InputBlock::CommitEdit()` generates `LOG_INFO` on edits; ensure interactive Console search doesn't flood Output.
- AiluHeadTool regenerated `Editor/Inc/generated/EditorApp.gen.h` because line-number-based `GENERATED_BODY` macro names changed after the new member/method; the generated diff is retained and was produced by the normal build dependency.
- A nested UI Scissor was not an intersection stack, so cell-level clipping could escape the table body during animated scrolling; fixing the renderer stack repairs this at the shared clipping boundary.
- The first preferences header used a namespace shorthand that AiluHeadTool interpreted as `Ailu::Ailu::Editor`; changing it to the repository's nested namespace form fixed reflection registration before the successful rebuild.
- `build-debug-smoke` initially could not write the configured external build tree `F:/AiluEngine/build/debug`; the same command succeeded with the required filesystem permission.
- The standalone service smoke retains 10,000 records after 80,000 concurrent messages and a forced 2,148-record pending burst; the final run reports 72,051 history evictions, 100 pending drops and 1 truncation in 4,340 ms. Aggregate `Test.exe` failures are outside the modified logging files.
- The original aggregate Named pipe and WidgetAsset failures were reproducible; after the narrow JSON-array and pipe-ACL fixes, those cases pass. The aggregate still has three Input/Graph failures and an access-violation exit, so it is not a clean repository-wide regression gate.
- M4 explicit inherited-handle whitelist behavior is validated on the current Windows runtime; the independent inheritable sentinel was excluded from the child. Win7 runtime verification remains unavailable.
